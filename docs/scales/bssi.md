# 贝克自杀意念量表（BSSI-19项自评版） 规格

> 程序里的题目、选项和分档文字一律从 `docs/scales/scales.json` 读取，不要照本文表格手抄。
> 本文是给人看的规格说明；本文和 `scales.json` 不一致时以 `scales.json` 为准，并提出来。
> 凡写着“见 OQ-xx”的地方，以 `docs/OPEN_QUESTIONS.md` 里该条的答复为准。

## 1. 来源

- 全部来自需求说明书“模块四”。甲方没有给纸质表，无法另行核对文字。
- 这份 19+2 题的条目和公开发表的 Beck 自杀意念量表（BSS）及其中文版条目不完全相同，0–5 / 6–9 / ≥10 三档分界的出处也需要甲方给，见 OQ-05。程序照说明书做。

## 2. 选项和计分

每题 3 个选项，键盘 1/2/3（含小键盘）。A=0，B=1，C=2。**没有反向题**：第1题（活下去的愿望）和第14题（控制力）的选项顺序说明书已经排好，A 都是风险最低的那一项，照录即可，不要再反转。

## 4. 跳题逻辑（说明书标注“开发者务必实现”）

1. 开始时只显示第1–5题。
2. 第4题和第5题**都**选 A（都得 0 分）：第6–19题不显示、按 0 分；第20、21题默认也不显示（OQ-06）；答完第5题即可提交出结果。
3. 第4题或第5题任意一个选了 B 或 C：接着显示第6–19题和第20、21题，全部答完才能提交（第20、21题可以空着）。
4. 改答案：如果先让第6–19题出现并作答，后来又把第4、5题都改回 A，第6–19题要重新隐藏，**隐藏的旧答案不计分**（总分只算第1–5题）。旧答案可以留在内存里，第4或5题再改成非A时恢复显示，也可以清掉，二选一，在 README 写明。
5. 第20、21题的文字永远不进总分。

## 5. 总分、分级和结果显示

总分 = 显示出来的第1–19题得分相加，满分 38（跳题时最多 10 分）。界面显示：**BSSI总分：XX分**，下一行显示分级文字。

| 总分 | 显示文字（说明书原文） | 界面样式 |
|---|---|---|
| 0–5 | 低风险 | 普通 |
| 6–9 | 存在自杀意念/准备 | 橙色醒目条 |
| 10–38 | 中高风险，建议立即进行临床干预访谈 | 红色醒目横幅，结果页最上方，字号最大 |

- 只显示上表的分数和文字，程序不另外加任何诊断、处置建议或解释。“建议立即进行临床干预访谈”是说明书原文，照录（OQ-20）。
- 第4或第5题不是 A、但总分 ≤5 时仍显示“低风险”。是否加一行事实提示“第4或第5题选了非A选项（已进入第6–19题）”，见 OQ-07；未答复时不加。
- 结果给不给患者看，见 OQ-08。
