## 2. 指导语

> 根据你过去一个月的睡眠习惯，对一个月中多数的白天和晚上的睡眠情况做准确回答。要回答所有问题。时间以24小时制填写。

来源：纸质表原文。是否显示见 OQ-11。

## 3. 题目和输入方式

### 第1题　近1个月，晚上上床睡觉通常是几点？

- 输入：时、分（24小时制）。两个下拉框，分钟 5 分钟一档；获得焦点时也可直接键入 `2330`、`23:30`、`930`、全角数字和全角冒号。
- 说明书原写“下拉框，仅作记录，不参与总分计算”，但成分D要用它算在床时间，所以这里参与计算，见 OQ-03。
- 默认值：空（必须填）。不要预填 23:00/07:00，免得患者不改直接提交。

### 第2题　近1个月，从上床到入睡通常需要多少分钟？

| 键盘 | 选项 | 得分 |
|---|---|---|
| 1 | A. ≤15分钟 | 0 |
| 2 | B. 16~30分钟 | 1 |
| 3 | C. 31~60分钟 | 2 |
| 4 | D. >60分钟 | 3 |

### 第3题　近1个月，通常早上几点起床？

- 输入：时、分（24小时制）。两个下拉框，分钟 5 分钟一档；获得焦点时也可直接键入 `2330`、`23:30`、`930`、全角数字和全角冒号。
- 说明书原写“下拉框，仅作记录，不参与总分计算”，但成分D要用它算在床时间，所以这里参与计算，见 OQ-03。
- 默认值：空（必须填）。不要预填 23:00/07:00，免得患者不改直接提交。

### 第4题　近1个月，每夜通常实际睡眠多少小时？

- 输入：小时 + 分钟（分钟 5 分钟一档），由时长自动换算成分C，同时用于成分D，见 OQ-03。
- 说明书原为四选一，选项如下，仅供参考（时长输入后程序按同样的分档换算）：

| 选项 | 得分 |
|---|---|
| A. >7小时 | 0 |
| B. 6~7小时 | 1 |
| C. 5~6小时 | 2 |
| D. <5小时 | 3 |

## 4. 时间输入的校验

在床时间（分钟）= (起床 − 上床) mod 1440，跨午夜自动处理（23:30 上床、06:30 起床 = 420 分钟）。

| 情况 | 处理 | 错误码（给测试用） |
|---|---|---|
| 上床和起床时间相同 | 不能提交，提示“上床时间和起床时间相同，请核对” | `SAME_TIME` |
| 实际睡眠时长为 0 | 不能提交，提示“请填写实际睡眠时长” | `SLEEP_ZERO` |
| 实际睡眠时长 > 在床时间 | 不能提交，提示“实际睡眠时长比在床时间还长，请核对” | `SLEEP_GT_TIB` |
| 在床时间 > 16 小时 | **可以提交**，但先弹出确认“在床时间 X 小时 X 分，请确认上床、起床时间是否填反或把 23 点填成了 11 点”；确认后照常计算 | 结果里 `warn_tib_long = true` |

## 5. 七个成分

每个成分 0–3 分。下表“采用”一列是本规格的默认，括号里是对应的待确认条目。

| 成分 | 名称 | 采用的算法 | 说明书原文 |
|---|---|---|---|
| A | 主观睡眠质量 | 第6题得分（OQ-02） | “直接等于 Q6 的得分”，Q6 是催眠药物题；并注明“如你原表无第6题，直接用 Q6药物 作为成分A” |
| B | 入睡时间 | 第2题得分 + 5a得分：0→0，1–2→1，3–4→2，5–6→3 | 相同 |
| C | 睡眠时间 | 第4题时长：>7小时→0；6小时≤时长≤7小时→1；5小时≤时长<6小时→2；<5小时→3（OQ-03、OQ-04） | “直接等于 Q4 的得分”（Q4 为四选一） |
| D | 睡眠效率 | 效率 = 第4题时长 ÷ 在床时间 × 100%：≥85%→0；75%≤效率<85%→1；65%≤效率<75%→2；<65%→3（OQ-04） | “>85% 计0分；75%~84% 计1分；65%~74% 计2分；<65% 计3分” |
| E | 睡眠障碍 | 5b–5j 九个小题得分相加：0→0，1–9→1，10–18→2，19–27→3 | 相同（5j 计分同其他小题） |
| F | 催眠药物 | 第7题得分 | “直接等于 Q6 的得分” |
| G | 日间功能障碍 | 第8题得分 + 第9题得分：0→0，1–2→1，3–4→2，5–6→3 | “Q7 + Q8”，同一组题 |

实现要求：

- 成分D 用整数比较，不要先算出百分数再四舍五入：`sleep*100 >= 85*tib` → 0，`>= 75*tib` → 1，`>= 65*tib` → 2，否则 3（`sleep`、`tib` 都是分钟）。84.6% 按 1 分，不能四舍五入成 85% 变 0 分。
- 界面上显示的效率四舍五入到 1 位小数，只用于显示，也用整数算：`tenths = (sleep*2000 + tib) // (2*tib)`，显示 `tenths/10`（例如 345/480 → 71.9%）。
- 5a 只进成分B，不进成分E。

## 6. 总分、分级和结果显示

总分 = A+B+C+D+E+F+G，范围 0–21。界面显示：**PSQI总分：XX分**，下一行显示分级文字。

| 总分 | 显示文字 |
|---|---|
| 0–5 | 睡眠质量很好 |
| 6–10 | 睡眠质量还行 |
| 11–15 | 睡眠质量一般 |
| 16–21 | 睡眠质量很差 |

这四档是说明书给的，和网上常见的中文 PSQI 解读一致；原版论文只用“总分 >5 为睡眠质量差”一条分界。照说明书做，不改。

是否另外显示七个成分分、在床时间、睡眠效率，见 OQ-16。
