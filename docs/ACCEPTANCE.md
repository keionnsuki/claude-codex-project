# 验收

> 两部分：A. 自动用例（`docs/acceptance_cases.json`，由 `tests/test_acceptance.py` 全部跑一遍）；B. 手工验收清单（界面、键盘、隐私、打包，最后要在 Windows 上逐条打勾）。
> 用例里的期望值是先手算、再用一个独立写的计分脚本复核过的。**测试不通过时改代码，不要改用例。** 如果认为某条用例本身错了，按 OPEN_QUESTIONS 的格式新加一条问需求方，确认后再改。

## A. 自动用例

### A.1 文件结构

```
{
  "meta":  {"version", "defaults": {用例默认采用的口径}, "note"},
  "sds":   [{"id", "desc", "answers": "20个字母", "item_scores": [20个数], "expect": {"raw", "standard", "grade"}, "expect_if_floor_rounding": {...}}],
  "sas":   [同 sds],
  "psqi":  [{"id", "desc", "input": {...}, "expect": {"tib_minutes", "efficiency_pct", "components": {"A".."G"}, "total", "grade", "warn_tib_long"} 或 {"error"}}],
  "bssi":  [{"id", "desc", "answers": {"1": "A", ...}, "expect": {"skipped", "shown", "total", "grade", "screen_positive"}}],
  "psqi_time_parse": [{"input", "minutes" 或 null, "desc"}]
}
```

字段说明：

- `answers`（SDS/SAS）：第 i 个字母是第 i 题选的选项，A–D 对应键盘 1–4。`item_scores` 是换算后的单题得分（反向题已经换算），用来定位是哪一题算错。
- `input`（PSQI）：`q1` 上床时间、`q3` 起床时间（"HH:MM"）；`q4_minutes` 实际睡眠分钟数；`q2`、`q5a`–`q5j`、`q6`–`q9` 是选项字母，题号按 `docs/scales/psqi.md` 的纸质表编号（第6题是主观睡眠质量，第7题是催眠药物）；`q5j_text` 是 5j 的文字。
- `answers`（BSSI）：键是题号字符串。有些用例故意包含“应被隐藏”的题的旧答案（BSSI-09），计分时必须忽略。`shown` 是应该显示的题号，按升序比较。`screen_positive` 表示第4或第5题不是 A。
- `efficiency_pct` 是四舍五入到 1 位小数的显示值，按 `docs/scales/psqi.md` 第5节的整数公式 `(sleep*2000 + tib) // (2*tib) / 10` 算，必须完全相等。其余字段也必须完全相等。
- `error`：`SAME_TIME`（上床起床时间相同）、`SLEEP_ZERO`（实际睡眠为0）、`SLEEP_GT_TIB`（实际睡眠比在床时间长），按这个顺序检查，命中第一个就返回。
- `psqi_time_parse`：`minutes` 是一天中的分钟数（23:30 → 1410），`null` 表示不合法。

### A.2 备用期望值（口径开关）

`expect` 是按 `meta.defaults` 的口径算的。如果 OPEN_QUESTIONS 的答复改了口径，测试要改用对应的备用期望值：

| 备用字段 | 什么时候用 | 对应开关 |
|---|---|---|
| `expect_if_floor_rounding` | OQ-01 选了“只取整数部分” | `ZUNG_ROUNDING = "floor"` |
| `expect_if_no_item6` | OQ-02 选了“不补第6题” | `PSQI_INCLUDE_ITEM6 = False` |
| `expect_if_ask_history_when_skipped` | OQ-06 选了“跳题后仍问第20、21题” | `BSSI_ASK_HISTORY_WHEN_SKIPPED = True` |

`test_acceptance.py` 读取 `config.py` 当前的开关，自动选用 `expect` 或备用字段。PSQI 在 `PSQI_ENABLED = False` 时整组跳过（pytest 的 skip，并写明原因“等待 OQ-02/03/04”）。备用字段是完整的期望对象，只出现在“换了口径结果会变”的用例上；没有备用字段的用例，换口径后期望不变。目前有：SDS/SAS 全部用例都有 `expect_if_floor_rounding`（很多和 `expect` 相同）；PSQI-03、PSQI-23、PSQI-26、PSQI-27 有 `expect_if_no_item6`；BSSI-01、BSSI-02、BSSI-09 有 `expect_if_ask_history_when_skipped`。

#### PSQI 时间输入解析

规则：先去掉前后空格，全角数字和全角冒号、点号转成半角，点号当冒号；带冒号时冒号前 1–2 位是小时、冒号后必须正好 2 位是分钟；不带冒号时 1–2 位数字只表示小时，3 位是“H MM”，4 位是“HH MM”；小时 0–23、分钟 0–59，否则不合法。

| 输入 | 结果 | 说明 |
|---|---|---|
| `23:30` | 23:30（1410） | 标准写法 |
| `2330` | 23:30（1410） | 四位数字不带冒号 |
| `930` | 09:30（570） | 三位数字：第一位是小时 |
| `0930` | 09:30（570） | 四位数字带前导0 |
| `9:30` | 09:30（570） | 一位小时带冒号 |
| `7` | 07:00（420） | 一位数字只写小时 |
| `23` | 23:00（1380） | 两位数字只写小时 |
| `0:00` | 00:00（0） | 午夜 |
| `00:05` | 00:05（5） | 午夜后5分钟 |
| `１２：００` | 12:00（720） | 全角数字和全角冒号 |
| `23.30` | 23:30（1410） | 用点代替冒号 |
| ` 23:30 ` | 23:30（1410） | 前后有空格 |
| `2400` | 不合法 | 24点不合法，应写 0:00 |
| `24:00` | 不合法 | 24点不合法，应写 0:00 |
| `2360` | 不合法 | 分钟超过59 |
| `23:5` | 不合法 | 冒号后分钟必须两位 |
| `12345` | 不合法 | 五位数字 |
| `` | 不合法 | 空 |
| `abc` | 不合法 | 不是数字 |
| `23:30:00` | 不合法 | 带秒 |

## B. 手工验收清单

在 Windows 上，先用 `python -m psyassess` 过一遍 B1–B5，打包后再用 exe 在另一台干净的电脑上把全部条目过一遍。每条打勾时写上日期和用的电脑。

### B1. 启动和整体

- [ ] 双击 exe 直接打开主窗口，没有黑色控制台窗口，没有安装步骤，不要求登录
- [ ] 每个页面最上方都显示“本工具仅供临床辅助评估使用，不能替代专业精神科医生的诊断。”，一字不差
- [ ] 1366×768 分辨率下所有页面完整显示，不用横向滚动；字够大，坐在诊室椅子上看得清
- [ ] 系统缩放 125%、150% 时字不发虚、不被截断
- [ ] 主页按 1–4 能分别打开四个量表；PSQI 未确认时按钮是灰色“待确认”，按 3 没反应或提示待确认

### B2. 键盘录入（拿一张填好的纸质表照着录）

- [ ] 作答页按 1/2/3/4（主键盘和小键盘都试）分别选中 A/B/C/D，选完自动跳到下一题
- [ ] BSSI 只认 1/2/3，按 4 没有反应
- [ ] ↑/↓ 能回到上一题改答案，改完分数跟着变
- [ ] 最后一题选完，按 Enter 提交；还有没答的题时按 Enter 会跳到第一道没答的题并提示（OQ-12）
- [ ] 鼠标点整行选项都能选中，不必点小圆点
- [ ] 反向题界面上选项顺序和正向题一样（A 在上），没有被倒过来
- [ ] 用 SDS-01（全按 1）录一遍，结果是 OQ-01 答复对应的分数；再用 SDS-04、SAS-02 各录一遍

### B3. PSQI（OQ-02/03/04 确认后）

- [ ] 上床、起床时间可以用下拉框选，也能直接键入 `2330`、`23:30`、`930`
- [ ] 时间输入框获得焦点时，按数字键是打字，不会去选选项
- [ ] 23:30 上床、06:30 起床，在床时间按 7 小时算（跨午夜）
- [ ] 11:00 上床、07:00 起床（PSQI-29）会先弹窗核对，确认后照常出结果
- [ ] 上床起床时间相同、实际睡眠为 0、实际睡眠比在床时间长，三种情况都不能提交，提示文字清楚
- [ ] 5j 选了 B/C/D 才出现填空框；不填也能提交（OQ-18）；填的文字不影响分数
- [ ] 按 PSQI-03 录一遍，总分 10“睡眠质量还行”；结果页的成分分按 OQ-16 显示或不显示

### B4. BSSI 跳题

- [ ] 一开始只显示第1–5题
- [ ] 第4、5题都选 A：第6–19题不出现，可以直接提交；第20、21题按 OQ-06 出现或不出现
