# 焦虑自评量表（SAS） 规格

> 程序里的题目、选项和分档文字一律从 `docs/scales/scales.json` 读取，不要照本文表格手抄。
> 本文是给人看的规格说明；本文和 `scales.json` 不一致时以 `scales.json` 为准，并提出来。
> 凡写着“见 OQ-xx”的地方，以 `docs/OPEN_QUESTIONS.md` 里该条的答复为准。

## 1. 来源

- 题目、选项、正反向、公式、分档：需求说明书“模块二”。
- 核对用：甲方给的纸质表（SAS.jpg）。纸质表上带 ※ 的题就是反向题，和说明书完全一致。
- 文字以说明书为准（说明书核心需求第5条要求严格照录）；纸质表写法不同的地方列在第4节最后一列，界面不显示，见 OQ-10。

## 2. 指导语

说明书没有给指导语。下面这段改写自纸质表，是否显示见 OQ-11（未答复时不显示）：

## 3. 选项、按键和单题得分

| 键盘 | 选项 | 正向题得分 | 反向题得分 |
|---|---|---|---|
| 1（含小键盘） | A. 没有或很少时间 | 1 | 4 |
| 2（含小键盘） | B. 少部分时间 | 2 | 3 |
| 3（含小键盘） | C. 相当多时间 | 3 | 2 |
| 4（含小键盘） | D. 绝大部分或全部时间 | 4 | 1 |

按键对应的是**选项**，不是分数。反向题在计分函数里换算，界面上任何地方都不要把选项顺序倒过来。

## 5. 计分

- 正向题（15题）：1、2、3、4、6、7、8、10、11、12、14、15、16、18、20
- 反向题（5题）：5、9、13、17、19
- 三方核对：说明书列表、纸质表 ※ 号、Zung 原量表的反向题，三者一致。
- 单题得分：正向题 A/B/C/D = 1/2/3/4；反向题 A/B/C/D = 4/3/2/1。
- 粗分 = 20 题得分相加，范围 20–80。
- 标准分 = 粗分 × 1.25，四舍五入取整（说明书原文“四舍五入”），范围 25–100。

实现要求：

```python
standard = (raw * 5 + 2) // 4   # 四舍五入（默认）
standard = (raw * 5) // 4       # 只取整数部分（OQ-01 若选这个）
```

不要用 Python 的 `round()`：它对 .5 是“银行家舍入”，`round(52.5)` 得 52，会把粗分 42、50、58 算错。也不要用浮点数乘 1.25 再取整。

- OQ-01 四舍五入还是只取整数部分（SAS 分级不受影响，但标准分数字会差 1）。
- OQ-09 重度那一档说明书漏了符号；按前后连续只能读成“≥70”，和常见中文手册一致。
- OQ-10 第1题“或者急 / 或着急”、第11题“而苦恼 / 苦恼”以谁为准。
- OQ-11 是否显示指导语。
- OQ-16 是否另外显示粗分。
