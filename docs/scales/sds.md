## 5. 计分

- 正向题（10题）：1、3、4、7、8、9、10、13、15、19
- 反向题（10题）：2、5、6、11、12、14、16、17、18、20
- 三方核对：说明书列表、纸质表 ※ 号、Zung 原量表的反向题，三者一致。
- 单题得分：正向题 A/B/C/D = 1/2/3/4；反向题 A/B/C/D = 4/3/2/1。
- 粗分 = 20 题得分相加，范围 20–80。
- 标准分 = 粗分 × 1.25，四舍五入取整（说明书原文“四舍五入”），范围 25–100。

实现要求：

```python
standard = (raw * 5 + 2) // 4   # 四舍五入（默认）
standard = (raw * 5) // 4       # 只取整数部分（OQ-01 若选这个）
```

不要用 Python 的 `round()`：它对 .5 是“银行家舍入”，`round(52.5)` 得 52，会把粗分 42、50、58 算错。也不要用浮点数乘 1.25 再取整。

## 7. 待确认（详见 docs/OPEN_QUESTIONS.md）

- OQ-01 四舍五入还是只取整数部分：粗分 42、50、58 的分级会不同。
- OQ-09 重度那一档说明书漏了符号；按前后连续只能读成“≥73（即 >72）”，和常见中文手册一致。
- OQ-10 题目文字以说明书为准还是纸质表为准（第1、7、18、19、20题写法不同）。
- OQ-11 是否显示指导语（“最近一星期”这个时间范围只在纸质表上有）。
- OQ-16 是否另外显示粗分、抑郁指数（粗分 ÷ 80）。
- OQ-21 第19题（“如果我死了别人会生活得好些”）选了C或D时要不要给医生一个提醒。
